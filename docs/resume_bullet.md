- Built ApneaGuard AI, an end-to-end sleep apnea detection and AHI-based severity-scoring system on PhysioNet ECG data, comparing XGBoost (HRV features) against a 1D-CNN (raw ECG) under a rigorously validated subject-level split. Achieved 0.60 PR-AUC and 0.60 F1 on held-out subjects (outperforming the classical 0.50 PR-AUC baseline), featuring structural explainability (Saliency/SHAP) and a decoupled, serverless FastAPI + PostgreSQL backend deployed across Render, Vercel, and Neon.
