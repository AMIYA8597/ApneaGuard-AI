- Built ApneaGuard AI, an end-to-end sleep apnea detection and AHI-based severity-scoring system on PhysioNet ECG data, comparing XGBoost (HRV features) against a 1D-CNN (raw ECG) under a rigorously validated subject-level split. Achieved 0.69 PR-AUC and 0.62 F1 on held-out subjects (outperforming the classical 0.61 PR-AUC baseline), featuring structural explainability (Saliency/SHAP) and a CI/CD-deployed FastAPI + PostgreSQL backend.
