# Compliance Notes

- This is a research/portfolio prototype using public, de-identified PhysioNet research data. It is not a diagnostic device, has not been clinically validated, and must never be described as such anywhere in this codebase, its documentation, or any resume/interview material derived from it.

- If this system is ever extended to accept real, non-public patient recordings, that is a materially different use case requiring its own privacy/compliance review before launch. Do not assume the current architecture's safeguards are sufficient for that scenario.
